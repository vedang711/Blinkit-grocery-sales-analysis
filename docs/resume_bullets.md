# Resume-ready bullets

### Recommended version

**Blinkit Grocery Sales & Operations Analytics | MySQL | Python | Power BI**

- Analyzed 5,000 grocery orders and supporting product, customer, delivery, marketing and inventory data using MySQL and Python to identify sales, customer-segment and operational patterns.
- Built an interactive Power BI dashboard with KPI and drill-down views for order revenue, product performance, delivery reliability, customer feedback, marketing efficiency and inventory-loss signals.
- Performed data cleaning, exploratory analysis and SQL-based business analysis to identify high-performing product categories, repeat-customer patterns, delivery issues and channel-level marketing opportunities.

### Why I changed the original wording

The supplied dataset does not contain a reliable repeated outlet dimension, so the project should not claim detailed outlet-performance analysis. It also does not contain direct inventory-on-hand or stock-out events, so the project uses the safer wording **inventory-loss signals** rather than claiming that the analysis directly optimises inventory.

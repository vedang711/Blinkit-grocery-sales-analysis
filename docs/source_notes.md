# Source & Privacy Notes

- The project was built from the dataset supplied for this conversation.
- The repository intentionally excludes the original customer PII fields: name, email, phone and full address.
- `blinkit_customers_anonymized.csv` contains only fields required for analysis.
- Raw customer feedback text is excluded from the GitHub-ready dataset; only structured rating/category/sentiment fields are retained.
- Before publishing publicly, verify the dataset's original license/usage terms if the files came from a third-party source.

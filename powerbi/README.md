# Power BI Deliverable

The repository contains everything needed to build the Power BI report:

- `DAX_measures.dax` — measures
- `data_model.md` — relationships and modeling decisions
- `dashboard_build_guide.md` — exact page/visual layout
- `../data/processed/` — cleaned fact/dimension tables

## Why there is no `.pbix` in this repository

A `.pbix` file must be created/saved by Power BI Desktop. The repository therefore provides a reproducible Power BI-ready model, measures, data and dashboard specification rather than pretending a binary report file was generated by code.

Open Power BI Desktop, load the processed tables, create the relationships in `data_model.md`, add the measures from `DAX_measures.dax`, and follow `dashboard_build_guide.md`.
